# Prediksi Diabetes — Deep Neural Network

Aplikasi Streamlit untuk memprediksi diabetes menggunakan model **Deep Neural Network** (TensorFlow/Keras) yang tersimpan sebagai `model_diabetes.h5`.

## Teknologi

- Python, Streamlit
- TensorFlow/Keras, NumPy

## Menjalankan aplikasi

```bash
pip install streamlit numpy tensorflow
streamlit run app.py
```
